# Instox

A simple billing and inventory management app for small shop owners.

## Problem

Small shop owners waste hours on manual price calculations, lose track of inventory, and have no visibility into whether their business is actually profitable.

## Solution

Instox automates billing, tracks stock, and shows profit per sale — so shop owners can make smarter decisions and grow their business.

## Target Users

- Small retail shop owners (textile, general store, footwear, etc.)
- Family-run businesses with 1-3 employees
- Revenue: ₹5-25 lakh/year
- Currently using: pen, paper, calculator, Excel

## Tech Stack

- **Frontend:** React / HTML-CSS-JS
- **Backend:** Python Flask / FastAPI
- **Database:** PostgreSQL / SQLite
- **Deployment:** Railway / Render / Vercel
